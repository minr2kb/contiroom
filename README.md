# 콘티룸

곡의 가사와 코드를 편집하고, 예배 콘티를 라이브 가사 화면과 인쇄용 문서로 이어 주는 웹 앱입니다.

## 주요 기능

- **곡 편집**: 가사 줄과 코드 위치를 편집하고 섹션 순서를 바꿀 수 있습니다. 악보 사진을 분석해 편집 가능한 초안을 만들 수도 있습니다.
- **콘티 구성**: 곡 순서, 키, 송폼을 정하고 YouTube 플레이리스트 주소를 연결할 수 있습니다.
- **라이브 화면**: 콘티의 가사를 전체화면으로 표시하고 키보드로 이동합니다. 표시 줄 수, 코드, 다음 가사 표시를 조정할 수 있습니다.
- **인쇄**: 곡이나 콘티를 A4 미리보기에서 조정한 뒤 브라우저의 인쇄 기능으로 PDF를 저장할 수 있습니다.
- **공유**: 곡과 콘티의 공개 범위를 설정합니다. 공개 곡은 저장하거나 비공개 사본으로 복제할 수 있습니다.

## 로컬 실행

Node.js 22 이상과 pnpm이 필요합니다.

1. Supabase 프로젝트를 준비하고 [`supabase/migrations`](supabase/migrations)의 SQL 파일을 파일명 순서대로 적용합니다. 기존 프로젝트에는 이미 적용한 마이그레이션을 다시 실행하지 말고 이력을 먼저 확인하세요.
2. 환경 변수를 설정합니다.

   ```sh
   cp .env.example .env.local
   ```

   | 변수 | 용도 |
   | --- | --- |
   | `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 URL |
   | `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase publishable 키 |
   | `OPENAI_API_KEY` | 악보 사진 분석에만 필요합니다. 사용하지 않으면 비워 두어도 됩니다. |

3. 의존성을 설치하고 개발 서버를 실행합니다.

   ```sh
   pnpm install
   pnpm dev
   ```

앱의 로그인 화면에는 회원가입 기능이 없습니다. 테스트할 계정은 Supabase Auth에서 준비하세요. 실제 `.env.local`은 Git에서 제외됩니다.
악보 사진을 분석할 때 업로드한 이미지는 앱 서버를 거쳐 OpenAI API로 전송됩니다.

## 공개 범위와 데이터

새 곡과 콘티는 기본적으로 비공개입니다. 공개 곡과 콘티는 로그인하지 않아도 읽을 수 있습니다. **공개 콘티에 담긴 콘티 소유자의 비공개 곡도 해당 콘티 화면에서는 읽을 수 있습니다.** 콘티를 공개하기 전에 포함된 곡을 확인하세요.

공개 곡의 **저장**은 원곡을 가리키는 즐겨찾기이고, **복제**는 편집 가능한 비공개 사본을 만듭니다. 원곡에 대한 접근 권한이 없어지면 저장 항목과 콘티 참조에는 사용할 수 없는 곡으로 표시됩니다.

## 패드 오디오

패드 오디오 파일은 이 저장소에 포함하지 않았습니다. 현재 앱은 `/pads/pad_{키}.mp3`를 요청하므로, 별도 파일을 `public/pads`에 준비하지 않은 설치 환경에서는 패드 다운로드가 동작하지 않습니다. 다운로드한 파일은 브라우저의 Cache Storage에 저장됩니다.

## 개발 명령

```sh
pnpm test       # 도메인 로직 테스트
pnpm typecheck  # TypeScript 검사
pnpm lint       # Biome 검사
pnpm build      # 프로덕션 빌드
```

Next.js, Supabase, TanStack Query, TypeScript를 사용합니다.
